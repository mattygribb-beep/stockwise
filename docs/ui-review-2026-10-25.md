## Verification and limits

- TypeScript, production build and relevant regression suites are run before publication.
- Shared-frame tests cover one main landmark, selected navigation, deep-link mapping and the five primary mobile destinations.
- Desktop navigation and tabs are inspected live after deployment. Responsive rules are reviewed in source; no physical phone/camera scan is claimed.
- Match Review remains a dated 64-item audit, not a live view of the full catalogue.
- Favourites, Buyer opportunities and Buying Desk plans remain distinct saved lists. The wording identifies their purpose; this pass does not merge user records.
- Public facts are shared; personal drafts and settings remain browser-local.
