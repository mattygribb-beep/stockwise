Source Stack Scanner

Open the Amazon seller storefront.
Restores a previous Source Stack export into this browser profile so you do not need to rescan the storefront.
Use after sorting the storefront (for example Best Sellers). Captures each ASIN's visible position and the current sort mode without clearing your main scan.
Visits only captured products that do not already have an EAN, UPC or GTIN. Existing titles, prices and identifiers are preserved.
On one Amazon /dp/ page, captures identifier rows, Product Information/Technical Details HTML, scripts, meta and data attributes. Downloads JSON for review.
After enrichment, exports only products where Amazon did not expose a usable EAN, UPC or GTIN.
