# Source Stack

**Know before you buy.**

Source Stack is a purchasing-intelligence prototype for UK resellers and small wholesale businesses. It helps users analyse an opportunity before committing capital, apply personal buying rules, remember product/EAN history, review wholesale catalogues, record purchases, and compare expected economics with actual outcomes.

## Current build — V1.2

- Product analysis with profit, ROI, margin, capital and revenue calculations
- BUY / TEST BUY / CONSIDER / WALK AWAY decision engine
- Configurable buying rules and monthly buying budget
- Selling-price source/confidence, including UNVERIFIED manual estimates
- Stock Memory and repeat-EAN recognition
- Opportunity lifecycle: Analysed → Purchased/Selling → Completed
- Expected-vs-actual purchase outcomes
- Portfolio purchasing intelligence and purchase history
- Wholesale catalogue prototype: upload, map, review, analyse, shortlist and order-builder concepts
- Supplier intelligence views

## Tech

- Next.js App Router
- React + TypeScript
- Tailwind CSS
- Lucide icons
- pnpm

## Run locally

```bash
pnpm install
pnpm dev
```

Then open `http://localhost:3000`.

## Deploy

The project is designed for GitHub → Vercel deployment.

## Status

This is an early product prototype. Some catalogue and supplier records are demo data. Demo information must not be treated as verified marketplace or supplier data.
